## 3. 差异化机会评估

### 真差异化（护城河）

1. **承诺双向追踪** — 这是 PromiseLink 独有的产品概念。7 个竞品中无任何一个提供"我答应对方什么 + 对方答应我什么"的双向承诺追踪 + 兑现率统计。这是最强的差异化锚点，应作为核心叙事。（证据：`README.md` L113 "双向承诺自动提取"、`features.html` 承诺追踪卡片）

2. **关联发现引擎** — 自动发现人脉间隐藏关联（共同公司/学校/资源互补/需求匹配），竞品中仅 Clay 有浅层关系图谱，但无"资源互补→合作机会"推理。这是真差异化。（证据：`README.md` L139-141 "关联发现 3 策略"）

3. **数据主权 + 商务场景的组合** — Monica 也有本地存储，但聚焦亲友关系；Clay/Dex/Cloze 聚焦商务但全云端。PromiseLink 是唯一同时满足"数据不出家门 + 商务关系经营"的玩家。

### 营销话术（非真差异化）

1. **"核心算法不依赖 LLM 可离线运行"** — 技术审查已发现 entity_resolution/promise_fulfillment 实际调用 LLM，此承诺部分失真。且对用户而言，"不依赖 LLM"是技术特征而非用户价值，竞品用户并不关心。（证据：`README.md` L26-27）

2. **"AI 增强经网关代理不留存云端"** — 这是隐私工程实现细节，竞品如 Clay 也有加密承诺。对 C 端用户说服力有限，对 B 端/合规场景才有杀伤力。

### 最大短板

1. **零自动数据采集** — Clay/Cloze/Dex 自动从邮件、日历、LinkedIn 拉取互动记录，PromiseLink 需用户手动录入或语音录入每一次事件。这是关系管理工具的"懒人悖论"：最需要工具的人往往最懒得录入。

2. **基础版入门门槛过高** — 需要 `pip install` + 配置 LLM API Key，而竞品 Dex/Clay 注册即用。pricing.html 的 FAQ 声称"基础版完全免费无功能阉割"，但实际需自配 API Key 才能用 AI 解析，否则核心闭环降级为纯文本手动管理。

3. **专业版"即将上线"形成定位真空** — buy.html 整页是"敬请期待"，pricing.html 专业版标注"即将上线"。竞品 Orvo 已上线语音→AI 摘要→关系图谱，PromiseLink 专业版的语音/OCR/邮件同步仍是规划，存在被抢先的风险窗口。

## 4. 市场定位与目标用户审查

### 目标用户推断

从官网 `features.html` 使用场景（销售跟进/会议纪要/人脉维护）和 `about.html` 愿景（"商务关系的本质是信任"）推断，目标用户为：**需要系统化经营商务关系的个人专业人士**（销售、顾问、创业者、投资人）。

**问题**：这一定位过于宽泛。Clay 明确锁定"Apple 生态用户"，Dex 锁定"LinkedIn 重度用户"，Cloze 锁定"邮件/Outlook 用户"。PromiseLink 没有明确的使用场景锚点——是给销售用的？给顾问用的？给创业者用的？不同人群的需求差异巨大。

### 基础版 vs 专业版分层合理性

| 维度 | 基础版 | 专业版 | 评估 |
|------|--------|--------|------|
| 用户画像 | 技术型用户（能 pip install + 配 API Key） | 非技术商务人士（扫码即用） | ✅ 分层逻辑合理 |
| 价值主张 | 数据主权 + 开源透明 | 省心（无需配 Key）+ 移动端 | ✅ 差异化清晰 |
| 入口体验 | 需 Python 环境 + LLM API Key | 扫码激活 | ⚠️ 基础版门槛过高，可能吓退 90% 潜在用户 |
| 转化路径 | 基础版 → 扫码升级专业版 | — | ✅ 转化设计巧妙 |

### 定价建议

当前定价为占位状态。基于竞品定价带（$9-25/月）和 PromiseLink 的差异化定位，建议：

- **专业版个人**：¥39-59/月（对标 Clay $10、Dex $12，考虑中国市场定价锚点下浮）
- **专业版年付**：¥399/年（制造年付折扣吸引力）
- **核心策略**：承诺追踪 + 关联发现为基础版独有功能（免费），语音/OCR/邮件/网关为专业版付费功能。用"承诺追踪"这个独创功能做免费获客钩子，而非依赖"开源"标签。

## 7. 给主理人的 Battle Card 要点

面对竞品时，PromiseLink 的差异化话术：

1. **vs Clay/Dex/Cloze（云端 SaaS 竞品）**：「他们的联系人存在他们服务器上，你的关系网络存在你自己的电脑里。数据不出家门，不是功能，是原则。」——主打数据主权 + PIPL/GDPR 合规，尤其对中国企业客户和隐私敏感的高净值人士。

2. **vs Monica（开源竞品）**：「Monica 帮你记住朋友的生日，PromiseLink 帮你兑现每一次商务承诺。承诺追踪 + 兑现率统计 + 关联发现，这是关系经营系统，不是通讯录。」——主打商务场景深度 vs 个人场景浅度。

3. **vs 所有竞品（承诺追踪独占）**：「每一个 CRM 都管你的待办，只有 PromiseLink 管你的承诺——你答应别人的，别人答应你的。兑现率就是你的个人信用资产。」——承诺双向追踪是无人覆盖的蓝海功能，应作为第一叙事。

4. **vs Orvo（AI 语音竞品）**：「他们把语音变成笔记，我们把语音变成承诺追踪和关系洞察。语音只是入口，13 步解析管线才是引擎。」——强调管线深度而非输入方式。

5. **防守话术（面对"为什么不自动同步邮件/LinkedIn"质疑）**：「因为我们不碰你的邮件服务器。你的邮件凭证不需要交给任何第三方。需要时你手动转发或语音录入，主动权在你。」——将"无自动采集"的劣势转化为"隐私优先"的优势叙事。
