# W5 Evidence Directory

This directory hosts W5 evidence manifests produced at run time. No
artifacts are committed here by hand. Per
`docs/design/W5_IMPLEMENTATION_READINESS_CHECKLIST_v1.md` §4.5, the
following files MUST be generated by their respective runners and are
**never pre-baked**:

| Path | Producer | Contract |
|---|---|---|
| `w5_antighost/manifest.json` | `scripts/quality/check_w5_antighost.py` | `W5_EVIDENCE_MANIFEST_SCHEMA_v1.json` |
| `w5_e2e/manifest.json` | `scripts/e2e/e2e_w5_real_user.py` | `W5_EVIDENCE_MANIFEST_SCHEMA_v1.json` |
| `w4_baseline.json` | W4 evaluator (already shipped in W4) | `w4-baseline-v1` |

Until W5 Implementation is authorized, this directory intentionally
contains only this README.

Do not add secret-bearing files, raw candidate tokens, or HMAC material
here.
